# Pepper Motors landing

Одностраничный адаптивный сайт по требованиям из тестового задания.

Визуальное направление основано на приёмах современных автомобильных брендов: контрастная тёмная сцена, крупная редакционная типографика, динамичные углы, технические метки и выразительная цветовая навигация. Композиция и код разработаны специально для Pepper Motors и не копируют готовый шаблон.

## Что работает

- баннерный слайдер с семью исходными баннерами;
- адаптивная вёрстка от 320 до 1920 px без горизонтальной прокрутки;
- мобильное меню, FAQ и плавающие кнопки связи;
- квиз с ветвлением, динамическим прогрессом и отметкой выбранных ответов;
- маски телефона для России, Казахстана и Беларуси через параметр `?geo=ru`, `?geo=kz` или `?geo=by`;
- строгая проверка телефона, канала связи и согласия;
- нормализация телефона до международного цифрового формата;
- сбор UTM, `yclid`, `gclid`, типа устройства, страницы и ответов квиза;
- события `dataLayer`, интеграция с Яндекс Метрикой при указании счётчика;
- неблокирующая отправка заявки: экран успеха показывается сразу, затем данные уходят на endpoint;
- локальная очередь заявок при отсутствии или ошибке endpoint.

## Подключение интеграции

В `config.js` укажите:

```js
window.PEPPER_CONFIG = {
  leadEndpoint: "https://example.ru/api/leads",
  analytics: { yandexCounterId: "12345678" },
  contact: { phone: "+79990000000", telegram: "https://t.me/example", max: "" }
};
```

Endpoint должен принимать JSON методом POST. Поля: `name`, `phone`, `channel`, `answers`, `attribution`, `metadata`.

## Перед публикацией

Нужно заменить демонстрационные тексты и заполнить реальные контактные данные, CRM endpoint, счётчик аналитики, юридически проверенный текст согласия и политику конфиденциальности.

## Локальный запуск

Откройте папку через любой статический HTTP-сервер. Например, в редакторе кода можно использовать Live Server.
